## Context

博客当前使用 Hexo 8.x + landscape 自定义暗色主题，部署在 GitHub Pages 上。现有的搜索功能是通过导航栏搜索图标跳转到 Google 搜索（`//google.com/search`），体验割裂且依赖外部服务。

需要实现站内全文搜索，让读者在不离开博客的情况下快速找到感兴趣的文章。

## Goals / Non-Goals

**Goals:**
- 实现站内全文搜索，无需外部服务依赖
- 支持中文内容搜索（子串匹配）
- 搜索结果实时展示，交互体验流畅
- 与现有暗色主题风格一致

**Non-Goals:**
- 不实现中文分词引擎（子串匹配已满足需求）
- 不实现搜索结果高亮
- 不实现搜索历史或搜索建议
- 不替换现有的 Google 搜索（仅在 UI 层面替换入口）

## Decisions

### 1. 搜索索引方案：hexo-generator-searchdb

**选择**: `hexo-generator-searchdb`

**理由**:
- Hexo 生态中最成熟的搜索索引生成插件
- 支持 JSON 格式输出，体积小、编码兼容性好
- 可配置索引范围（posts/pages/all）和内容格式
- 构建时自动生成，无需额外构建步骤

**备选方案**:
- `hexo-generator-search`: 功能类似，但已较久未更新
- Algolia/MeiliSearch: 需要外部服务，增加运维复杂度

### 2. 搜索 UI：自定义实现

**选择**: 在主题中自定义搜索 UI 组件

**理由**:
- 现有主题已有搜索图标入口和展开动画的基础
- 自定义 UI 可完美适配暗色主题风格
- 避免引入额外的前端框架依赖

**实现要点**:
- 复用导航栏搜索图标作为入口
- 使用 XMLHttpRequest 加载搜索索引 JSON
- 前端 JavaScript 实现实时过滤和结果展示
- 中文搜索通过 `indexOf` 子串匹配实现

### 3. 中文搜索策略：子串匹配

**选择**: 使用 `String.indexOf()` 进行子串匹配

**理由**:
- 中文不需要严格分词，子串匹配已能覆盖大部分搜索场景
- 实现简单，无额外依赖
- 性能可接受（博客文章数量有限）

**局限**:
- 无法处理同义词或语义搜索
- 搜索"AI"不会自动匹配"人工智能"

## Risks / Trade-offs

- **[性能]** 搜索索引较大时，前端加载可能有延迟 → 限制索引内容为标题+摘要，不包含全文
- **[中文匹配]** 子串匹配可能返回过多结果 → 通过限制展示数量（10条）缓解
- **[浏览器兼容]** 使用 XMLHttpRequest → 兼容所有现代浏览器

## Migration Plan

1. 安装 `hexo-generator-searchdb` 依赖
2. 在 `_config.yml` 中添加搜索配置
3. 创建搜索 UI 组件（JS + CSS）
4. 修改主题模板，集成搜索组件
5. 构建验证
